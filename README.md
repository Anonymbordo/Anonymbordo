OSTİM Teknik Üniversitesi Yapay Zeka Mühendisliği öğrencisiyim. Yapay zeka alanında yalnızca teorik bilgi edinmeye değil, gerçek dünya problemlerine yönelik uçtan uca sistemler geliştirmeye odaklanıyorum.

Teknik çalışmalarım; makine öğrenmesi, derin öğrenme, bilgisayarlı görü, büyük dil modelleri, RAG sistemleri, yapay zeka ajanları, MLOps ve yapay zeka destekli web uygulamaları üzerine yoğunlaşıyor.

Bugüne kadar nesne tespiti ve takibi, medikal görüntüleme, grafik tabanlı öğrenme, LLM uygulamaları ve SaaS ürün geliştirme gibi farklı alanlarda projeler geliştirdim. Python, PyTorch, FastAPI, React, Next.js, Docker, PostgreSQL ve bulut teknolojileriyle uçtan uca ürün geliştirme deneyimine sahibim.

Hedefim, güçlü yapay zeka mühendisliği temellerini yazılım geliştirme yetkinlikleriyle birleştirerek ölçeklenebilir, üretime hazır ve gerçek problemlere çözüm sunan yapay zeka ürünleri geliştirmek.
